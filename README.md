# RIMK Pneus e Paletes

Site comercial institucional desenvolvido com React e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar versão de produção

```bash
npm run build
npm run preview
```

## Antes de publicar

- Substituir o link genérico do Instagram pelo perfil oficial da RIMK.
- Configurar o número oficial de WhatsApp no link de contato.
- Confirmar fotos, logotipo e informações comerciais oficiais.
